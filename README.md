# Moki — Brand Identity

Brand identity and packaging design for Moki, a playful ice cream shop.

| | |
|---|---|
| **Project** | Brand Identity, Packaging |
| **Brand** | Moki |
| **Industry** | Ice cream shop |
| **Scope** | Logo, submark, color palette, typography, pattern, packaging, stationery, storefront |

## Idea

Moki is a cheerful ice cream brand built around small, sweet moments. The personality is playful, friendly and modern.

The logo uses round, soft letterforms and replaces the "o" with a swirl of soft serve in three pastel tones. The same swirl works on its own as a submark. A wavy ribbon of the palette colors forms the brand pattern and runs across cups, tubs, bags and cards.
